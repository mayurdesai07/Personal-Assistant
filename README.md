# Zara - Personal AI Companion

Personal AI assistant web application with dark mode UI, soothing female voice, self-learning companion memory, calendar/birthday tracker, quick capture parser, and integrations for Gmail, College ERP, NxtWave, and WhatsApp.

## 🚀 Live Demo
- **Vercel Production Deployment:** [https://zara-personal-ai.vercel.app](https://zara-personal-ai.vercel.app)

## 💻 Local Setup
1. Clone this repository:
   `ash
   git clone https://github.com/mayurdesai07/Personal-Assistant.git
   cd Personal-Assistant
   `
2. Install Python dependencies:
   `ash
   pip install -r requirements.txt
   `
3. Run the server:
   `ash
   python app.py
   `
   Or double-click start_zara.bat on Windows.
4. Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.
